# Taskwell

A small web app starter for learning Codex. It uses React, JavaScript, and Vite. Todos are stored in this browser with `localStorage`.

## Start the app

1. Install [Node.js](https://nodejs.org/) if you don't already have it.
2. In this folder, run `npm install` once.
3. Run `npm run dev` and open the local URL Vite prints (usually `http://localhost:5173`).

## Useful commands

- `npm run dev` — start the development server
- `npm run build` — make a production build
- `npm run preview` — preview the production build locally

## First features

- Add a todo by typing and pressing Enter or selecting Add task.
- Mark tasks complete, filter the list, or remove a task.
- Your list stays in this browser after refresh.
